## Routing lessons
- A Morning Brew flagship issue can create durable pages outside pure business/finance when a short item contains reusable evidence and mechanisms. The cyclospora item warranted a public-health/food-safety note because it had concrete case counts, causal pathway, tracing difficulty, and surveillance-program context.
- Bank-earnings items should not automatically become one note per bank. When the issue frames several banks together around a shared mechanism (AI infrastructure fees + trading volatility + IPO/M&A activity), create a cycle/mechanism concept page and update company-specific pages only when there is a clear existing target.
- Data-center moratorium items should update both the local-externality page and the broader AI data-centre backlash page: the former captures noise/water/grid/community costs; the latter captures permitting/governance consequences.
- Keep sponsor blocks, games, sports jokes, recs, referral copy, trivia, and routine one-line headlines source-only unless they connect to an existing durable page.
