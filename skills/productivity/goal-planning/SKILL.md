# Goal Planning

## When to Use
Use for ambitions needing outcomes, milestones, projects, habits, and actions.

## Steps
Read current KB first. Preserve the user's priorities. Define outcome, definition of done, constraints, success criteria, milestone, next action, supporting habits, review cadence, adjustment trigger, and status. Update canonical note and tracker without duplicating authority.

## Pitfalls
Never infer outcome progress from task volume or elapsed time. Avoid fake precision.

## Verification
- [ ] Definition of done
- [ ] Concrete next action
- [ ] Review cadence
- [ ] Progress criteria explicit
