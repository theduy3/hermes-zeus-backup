# Resource Library

## When to Use
Use when a URL or source must be saved, retrieved, or recommended.

## Steps
Inspect the original first. Search library before recommendation. Record canonical URL, access date, origin, purpose, capabilities, limits, and retrieval trigger. Retain commands only when documented by the source. Reopen original source for consequential use.

## Pitfalls
A saved resource is not endorsement or verified truth.

## Verification
- [ ] Original inspected
- [ ] URL/date recorded
- [ ] Limits retained
