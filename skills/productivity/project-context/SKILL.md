# Project Context

## When to Use
Use before planning or acting on a project.

## Steps
Read rules, project summary, canonical note, and newer records. Capture purpose, outcome, status/phase, scope/non-goals, priorities, decisions/rationale, assumptions, constraints, sourced metrics, deadlines, risks, blockers, links, and next executable action.

## Pitfalls
Do not present forecasts as facts or allow summaries to become stale.

## Verification
- [ ] Current record read
- [ ] Facts/assumptions/decisions separated
- [ ] Blocker and next action explicit
