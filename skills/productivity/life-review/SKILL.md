# Life Review

## When to Use
Use for daily, weekly, monthly, or quarterly reviews.

## Steps
Read canonical goals/projects and tracker data. Report completed actions, stalls, blockers, habit consistency on scheduled days, and metric changes with coverage. Separate observations from explanations. Update status only with evidence or confirmation; propose few next actions.

## Pitfalls
Avoid guilt language, causal claims, and treating every metric as a target.

## Verification
- [ ] Current evidence used
- [ ] Coverage and uncertainty stated
- [ ] Status changes justified
